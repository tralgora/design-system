Color · Foundations

Dark surfaces. Three signals. No decoration.

Color carries meaning, never mood. Green is strength/active. Blue is structure/macro. Red is risk. Amber is caution. Everything else is a surface or text token. Data-viz uses a separate hue-rotated ramp so charts don't fight semantic chips.

Do

Use green only for genuine strength/active signals. Use red only for genuine risk. Use blue for macro and neutral structure. Let everything else be text or surface tokens.

Don't

Don't use green as a generic "primary" CTA color. Don't use red for cancel/secondary. Don't introduce new hues for decoration. No gradients on buttons. No green or red on data-viz lines unless the chart is literally P&L.
